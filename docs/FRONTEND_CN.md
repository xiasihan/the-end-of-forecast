# EndForecast Web 控制台 — 使用指南

EndForecast Web 控制台是一个生产级 ML 预测平台。上传数据、描述目标，即可实时观察完整的 10 阶段 Pipeline 执行过程，包括流式输出、LLM 决策日志和可部署的 API。

## 启动平台

### Docker（推荐）
```bash
docker-compose up
# 前端：http://localhost:3000
# 后端：http://localhost:8000
```

### 手动启动
```bash
# 终端 1 — 后端
cd endforecast
uvicorn endforecast.web.app:app --reload --port 8000

# 终端 2 — 前端
cd frontend
npm install
npm run dev
# 打开 http://localhost:3000
```

## 创建项目

点击左侧的**新建项目**按钮：

```
┌─────────────────────────────────────────────┐
│  新建项目                               [✕] │
│                                             │
│  项目名称                                   │
│  ┌─────────────────────────────────────────┐│
│  │ 例如：安徽价差预测                       ││
│  └─────────────────────────────────────────┘│
│                                             │
│  预测目标                                   │
│  ┌─────────────────────────────────────────┐│
│  │ 例如：预测安徽电价价差方向上涨或下跌     ││
│  └─────────────────────────────────────────┘│
│                                             │
│  目标列       时间列      ID 列（可选）      │
│  ┌──────┐    ┌──────┐    ┌──────┐          │
│  │ y    │    │ ds   │    │      │          │
│  └──────┘    └──────┘    └──────┘          │
│                                             │
│  ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐  │
│  │     📁 拖拽 CSV/Parquet 文件           │  │
│  │     或点击浏览                          │  │
│  └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘  │
│                                             │
│  [ 取消 ]      [ 创建并运行 Pipeline ]      │
└─────────────────────────────────────────────┘
```

1. **项目名称** — 方便识别的名称。
2. **预测目标** — 用自然语言描述预测问题。这段文字会发送给 LLM Agent，指导模型选择、预处理和特征工程。
3. **列映射** — 指定哪列是目标 (`y`)、时间戳 (`ds`)、以及可选的分组 ID。
4. **上传数据** — 拖拽或点击浏览。支持 CSV、Parquet、Excel 文件。
5. 点击**创建并运行 Pipeline** — 项目创建后立即开始运行。

## Pipeline 执行过程

Pipeline 启动后，终端区域实时流式输出每个阶段的进度。

### 阶段卡片

10 个阶段每个都以可折叠卡片的形式展示：

```
┌─ 阶段 1：数据理解 ──────── 2.3s ── ✅ 已完成 ── [▼] ──────────┐
│                                                                  │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐          │
│  │ 任务类型 │ │ 行数     │ │ 列数     │ │ 缺失率   │          │
│  │ 分类     │ │ 6,360    │ │ 3        │ │ 0.0%     │          │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘          │
│                                                                  │
│  [标签噪声]                                                      │
│                                                                  │
│  ┌─ 特征指纹诊断 ─────────────────────────────────────────────┐ │
│  │ 平稳性：ADF=-0.25 — 无法拒绝单位根假设。建议一阶差分。    │ │
│  │ 自相关：中等 (ACF1=0.588)。滞后特征有帮助。               │ │
│  │ 稀疏度：61% 为零值。考虑零膨胀模型。                      │ │
│  └────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

**卡片行为：**
- **运行中的阶段**：自动展开，黄色边框脉冲动画，旋转图标。
- **已完成的阶段**：折叠为摘要行，点击标题展开。
- **失败的阶段**：红色边框，错误信息始终可见。
- 根据阶段类型渲染不同内容（基线表格、指纹诊断、Holdout 分数等）。

### 阶段进度追踪器（右侧面板）

右侧面板显示实时更新的垂直步进器：


## 部署 API

运行成功后，可以将模型部署为生产 API：

### 1. 创建 API Key

```bash
curl -X POST http://localhost:8000/api/keys \
  -H "Content-Type: application/json" \
  -d '{"name": "生产密钥"}'

# 返回：
# {"id": "abc123", "name": "生产密钥", "prefix": "ef_XyZ...",
#  "raw_key": "ef_XyZ1234567890abcdef..."}  ← 保存好！仅显示一次。
```

### 2. 发起预测

```bash
curl -X POST http://localhost:8000/api/projects/PROJECT_ID/predict \
  -H "Authorization: Bearer ef_XyZ1234567890abcdef..." \
  -H "Content-Type: application/json" \
  -d '{"data": [
    {"ds": "2026-09-01 00:00:00", "y": 362.0}
  ]}'
```

### 3. 下载独立的预测器

在 Dashboard 中点击**下载 predictor.py**，或使用命令行：

```bash
curl http://localhost:8000/api/projects/PROJECT_ID/runs/RUN_ID/export \
  -o predictor.py
```

导出的文件是完全自包含的 Python 脚本，包含训练好的模型、预处理流程和精修策略——可直接用于 CI/CD 或手动部署。

## 国际化

平台支持中文和英文，默认为英文。

**切换语言：**
- 点击顶部栏的 🌐 **EN/中文** 按钮。
- 偏好设置保存到 `localStorage`，跨会话持久化。

所有界面文字自动本地化，包括：
- 导航和按钮
- 阶段名称（10 个阶段）
- Pipeline 状态信息
- Dashboard 指标
- LLM Agent 决策标签
- 错误消息和提示

要添加新语言，参考 `en.json` 的结构创建 `frontend/src/locales/{lang}.json`。
